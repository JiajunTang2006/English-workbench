# 专项推题入口修复

2026-10-01，源码版本 1.0.0，未制作新安装包。

## 现场复现与原因

在用户当前 Safari 的 `127.0.0.1:8765` 页面，从 TeachMate 首页进入“插件 → 专项推题 → 打开推题”，提示 `el.closest is not a function`，未打开任何推题界面。

没有打开教学任务时，推题入口会通过程序调用任务创建操作，传入普通参数对象。此前任务菜单收起逻辑未经检查就调用页面元素的 `closest` 方法，导致此路径直接失败。已有任务内的插件入口不走该分支，所以之前测试未覆盖这个问题。

## 修复

- 任务菜单逻辑仅在参数确实提供 `closest` 方法时执行，兼容程序调用。
- 提供任务创建入口，并让推题流程在新任务保存成功后直接进入练习生成页；普通任务创建保持原有流程。
- 专项练习工作区采用本地功能的就绪判断，不再因缺少对应聊天能力名而误标为“待配置”。插件实际启停与后端权限检查保持原有逻辑。
- 未配置生成模型时显示原因和“配置生成模型”入口，避免发送注定无法生成的请求。
- 回归中发现保存任务阶段时，本地“根据反馈调整教学”草稿操作可能被忙碌状态吞掉；让这些仅准备聊天草稿的操作立即响应，异步保存继续保留并发保护。
- 更新页面资源版本，刷新后可以加载修复。
