# TeachMate 前端布局改造 · 2026-09-30

源码版本 1.0.0。本次按已确认的布局建议实施，沿用现有教学任务、专项推题和反馈功能。

## 已落地的布局

- 默认以对话为主，顶部摘要集中显示任务名称、班级、学生姓名与学号、绑定考试和课时。任务对象与设置可从摘要进入，聊天输入区沿用任务范围。
- “任务内容”按需展开，分为练习、资料、反馈三个页签；四个教学阶段收进状态菜单，教师可以自由切换。
- 大窗口中任务内容位于对话右侧；1200px 及以下采用单个内容区切换。较窄窗口保留清晰的返回入口，输入框固定在对话区域底部。
- 教学材料编辑、练习生成、选原错题、逐题作答、复测导入及题目修订进入主工作区。简单对象设置和判断修正使用短弹窗。
- 练习详情采用题目导航与当前题目预览；答案、解析和提示按需展开。宽窗口可同时打开对话，较窄窗口在编辑和对话间切换。
- 来源信息展示阅读原文的全文／节选／不采用建议及理由。保留了来源附件页的题目可对照原始 PDF，并定位页码；另提供新窗口查看入口。教师可通过题目修订修改语篇。
- 草稿卡片突出核对采用，已采用练习突出打印；反馈页根据该练习的实际作答汇总突出录入作答、核对作答或安排复测，其他操作收进更多菜单。
- 保留暖色主题，提高任务正文和辅助文字的对比度，减少卡片层层边框。历史对话不重复显示相同标题和摘要。

## 数据及交互保护

同一编辑区在后台刷新、打开／收起对话及切换 WorkBench／TeachMate 时保留原始表单节点，未保存内容、输入光标、滚动位置和已选择的导入文件随之保留。切换到其他教学任务或明确返回任务内容，会结束当前编辑区。

作答状态汇总仅增加每份练习的作答数量和待核对数量；使用既有记录，不改变评分规则或掌握判断，不需要新增数据库迁移。学生打印稿包含阅读材料，隐藏答案、解析和提示。

PDF 对照读取既有附件，不触发新 OCR 或付费模型调用。当前预览使用客户端内置 PDF 显示能力；浏览器自动化验证了鉴权下载、来源页定位和预览清理，未替代实际桌面客户端的 PDF 渲染走查。
