# 试卷设置与小分读取（2026-10-01）

源码版本保持 1.0.0，未制作新安装包。

## 教师操作

在「班级与设置 → 试卷设置」保存默认分布；在「成绩管理」选择考试，点击「考试设置」单独调整这场考试。两处使用相同的固定题型顺序：听力理解、阅读理解、完形填空、词汇运用、语法填空、书面表达。

每个题型一行「第［起始］题，到第［结束］题」，只填写两个整数。例如1到20分别填1和20；只有一题时两栏填相同数字；没有该题型时两栏都留空。无需输入题型名称或满分。起止漏填、范围倒置或题号重叠时会提示，保留编辑内容。

新建考试时保存当前默认分布的独立副本。已有且没有确认试卷的考试在首次小分上传时可使用默认分布；已有确认试卷或单场设置的考试不会随默认修改被重写。「使用默认分布」只填入单场编辑表，点击保存后才应用。

在「成绩管理 → 上传小分」粘贴三列：题号、学号或姓名、得分。程序按已确认的本场分布查找题型并写入数据库；原有带题型的四列／五列导入仍可使用。同名无法唯一定位、题号有歧义、重复成绩或负分会被拒绝。

## 数据与统计

默认和单场分布保存在SQLite设置表，单场设置同时生成已确认的试卷版本、题型和逐题记录。已有小分按原印刷题号迁移到新版本，保留实际分数，包括真实0分。题干、答案、来源页、知识点及原卷附件随匹配题号保留。删除已录入小分的题号会被拒绝；并发过期保存会提示重新读取。

学生画像能力图、小分明细及聊天学习证据读取同一套已确认试卷和成绩记录。没有逐题满分时只统计实际每题平均得分，不虚构得分率、错题或掌握率；题型间原本分值可能不同，因此平均得分不能直接解释为跨题型掌握程度。原卷提供有效满分且数据齐全时可展示得分率。小分未录全的题型不计入均值，缺失值不画成0；不足三个有效题型时显示条形图。

兼容现有分大题编号的原卷：连续小题范围显示「第X大题」，仍只填起止两个数字；导入可使用1-1等完整题号，单独大题号有歧义时不猜测。历史题号不连续时显示多组起止数字；每段独立保存，不扩大范围或遗漏原题。

## Safari补充检查与兼容修复

实际核对时发现旧数据会把4-1等小题号直接保存为question_no，没有单独的sub_question_no；此前设置接口返回这些题号时，会被界面误读为普通数字区间。现在读取时将两种存储形式统一编码为明确的小题范围，保留原题号，不更改历史成绩。Safari已正确显示各大题的1到10范围和作文1到1，未再出现误报「原题号不连续」。

成绩管理里的两类入口已区分：「考试设置」调整题型分布，「考试信息」调整原有考试名称、日期等信息。补充回归30项通过，桌面和窄屏的试卷导入流程2项通过，语法检查通过。更新通过正常启动器加载，不读取日志中的凭据，未制作安装包。此次原生复查未复现上一轮截图主内容空白，因此不认定空白已有确定的代码原因。

## 阅读题型合并（2026-10-01）

固定顺序现在为听力理解、阅读理解、完形填空、词汇运用、语法填空、书面表达。任务型阅读作为旧格式别名接收，统一保存为阅读理解，不再单列入口或能力图轴。原题正文、答案、知识点和来源保留。

迁移20261001_0035合并旧试卷题型、两处范围配置、学校导入的题型汇总和错题快照。试卷设置与考试设置独立，原题号和逐题结果ID保持不变；设置修订号递增，阻止旧页面覆盖新配置。连续范围自动压缩，不连续范围及不同大题的小题范围分别显示两个数字，保存时保留所有题号。

能力图从合并后的逐题事实计算：有满分时使用合计得分／合计满分；无满分时使用每题平均得分。不会简单平均原来两类的百分比。缺失小分继续标为不完整，零分仍参与统计。新导入的旧别名在保存题目时统一转换，学校同步和三列／带题型的小分导入均兼容。
