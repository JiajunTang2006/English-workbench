## 核心验收覆盖

- 同名候选、教师选定引用、学号、别名冲突、换人、比较、全班与教师纠正续接；未知点名不沿用旧学生，严格模式续接与历史姓名还原。
- 源事实修改后缓存失效、重复查询有限上限；既有 Harness 并发范围、取消、超时和清理回归。
- 个人/小组对象校验、越界学生与错误题号拒绝、未采用不能录入、批量失败原子回滚、未来作答日期拒绝、重复提交幂等。
- 数值/分数等价答案、开放题待核对、教师修正留痕与版本冲突；AI 反馈建议不改变最终判断，供应商未返回用量保持未知。
- AI 生成失败、工厂异常、费用确认前无调用、生成中教师更新任务、无效题量或 `questions=null` 不产生半成品练习。
- 已确认原错题索引、原题复用不计作独立新题、阅读原文逐字核对、编造来源拒绝、插件停用阻止新增写入、历史仍可读。
- 教师修订保存独立题目版本；同目标新题复测拒绝原题重复，提示后完成与独立首次新题/复测分开统计。
- 从旧结构 0032/0033 升到 0034，已有对话、报告、教学任务目标与材料仍保留，新对象字段正确默认班级。
- 页面中的插件打开、核对采用、打印答案隔离、录入、修正、题目修订、刷新恢复以及既有 CSV/Excel 反馈导入。

## 基线与未完成的外部验证

改造前保留了相关源码快照及 35 项既有定向回归通过记录；现有回放采用固定合成学生和脚本化 Provider，适合验证身份、范围、状态和失败路径。这不是线上模型的成本或自然度基线。

G01：尚未对真实第三方模型进行多轮相同教师任务的改造前后对照；没有可报告的 Token 节省比例、真实语义准确率或自然度评分。新代码已经记录调用用量、估算、时延与查询命中，后续可据此测量。

G04：尚未进行教师真实课堂走查；阅读原文是否值得保留、题目实际难度、答案语义正确和学习增益需要教师反馈。自动化通过不能代替这些验收。

PDF 没有确认题目索引/正文时不会臆造原题；页级文本不完整需要教师补充。费用估算仍依赖已维护的模型价格，未知价格不会被当作免费。
