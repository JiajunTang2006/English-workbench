## 已完成的工程流程

- 教师点名、学号、确认引用和别名在本地名单解析。同名或近似名称只返回待确认候选；显式未知人物不会错误沿用上一位学生。当前学生集合、教师纠正与身份快照随运行保存，换人、比较、全班追问可在同一对话完成。新的教师工作模式统一保留学生姓名，电话、学号及其他受保护信息继续清理；API 也支持 `identity_mode=strict`，并沿用该会话模式。历史编号按当时快照恢复。
- 数据库连接与本轮业务范围分开，Harness、Bridge、旧运行路径使用相同本轮范围。普通聊天不再要求固定报告排版；模型可以直接讨论或按需取证，正式报告仍进行证据与输出校验。无工具模型有明确的一般问答/本地预查路径，不能伪装成已自主查询。可选推理参数依模型能力发送，用量缺失显示未知。
- 同一运行的只读查询可命中有限缓存，源成绩/题目/名单/附件变化会失效；缓存最多 8 项，每项 18,000 字符，累计最多 20 次只读调用。练习表现查询始终读取最新记录。保留现有循环、费用、超时、取消、重连控制及最终回答额度。
- 教学任务支持班级、个人或小组。专项练习依据已有逐题成绩、缺失项、教师观察/纠正、教材与已教条件生成；分层建议可调整。题目结构、目标、难度档位、重复、选项和可计算数值答案先由程序检查；解法、实际难度与教学适用性保留为教师核对事项。
- 草稿核对后采用；教师可以编辑题干、阅读原文、选项、答案、解析和提示，保存为新练习版本，旧版本和旧作答保留。学生打印稿仅有题目、所需原文、选项和作答空间；教师答案单独打印。
- 教师可逐题录入或 CSV/Excel 批量导入作答，记录日期、提示级别与答案查看。重复提交标识保持幂等；教师修正保留原判断与理由。选择/数值题依据已采用答案核对，开放题待核对；AI 反馈仅为建议，不能改写教师最终判断。
- 新题复测保留同目标和相同学生对象，可指定题量及计划日期，禁止直接重复原练习题干。统计答对、提示后答对、独立首次新题与复测；一次答对不自动认定稳定掌握。教师聊天可按需查询这条练习数据链。

## 专项推题插件的使用

1. 打开 TeachMate 左侧“插件”，找到 **专项推题**，可启用/停用或点“打开推题”；聊天“工具 → 选择调用插件”也可选择它。
2. 先打开或新建教学任务，设定班级/个人/小组、学习目标和教学条件。任务工作区提供“查看弱项与建议分组”“生成专项练习”和“从原错题选题”。
3. 核对草稿的题目与答案，再采用、打印。课堂结束后录入/导入作答，必要时教师修正或请求 AI 反馈建议，然后安排同目标新题复测。

## PDF 原错题与阅读原文

使用教师已经确认的试卷版本、题号、学生实际失分、来源页码与现有页级提取/OCR 文本。**PDF 已存入库不代表每道题都有完整题干、答案与语篇**；缺少索引或正文时需要先补充并确认试卷结构，本轮不会自动重跑整卷 OCR。

独立填空复用原题；完形、语篇填空按上下文题处理。阅读题一次模型调用建议 `full / excerpt / omit`，说明与目标相关的取舍。程序核对引用是否来自相应来源文本，并保存试卷版本、原题、页码、源文件摘要与取舍理由。默认只取索引页及相邻页，过长内容明确拒绝，避免静默截掉答题所需条件。

全文/节选的教学价值与语篇完整性仍由教师核对。不能证明来源完整时不保证已得到整篇文章；模型不得编造缺页。原错题重做只记作巩固，**不计入首次独立新题表现**。仅改数字或改措辞是否足以测试迁移，也需要教师判断，程序的重复检查不等于语义证明。

## 用量与模型边界

新生成、阅读取舍和反馈默认各一次模型调用，按模型上下文/输出上限估算费用；超出本次预算后须点击明确的费用确认。运行保存输入各部分估算、模型调用时延及供应商实际用量。练习预览显示预估费用和已返回的实际 Token/费用；供应商未返回时显示未知，不显示为免费。

缓存和上下文裁剪已实现，但**尚无真实模型改造前后对照测得的 Token 节省比例**。目前费用门禁仍依赖应用维护的已知模型价格；未知价格模型会明确提示不能估算，不假设其免费。第三方兼容协议由合成 Provider 测试覆盖，不能代替每个厂商线上验收。
