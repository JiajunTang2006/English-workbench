## 1. 产品简介

初中英语工作台是一款给英语老师自己用的教学管理软件，装在办公电脑上就能跑，不依赖机房和云服务。平时最花时间的几件事——管班级、录成绩和分析、记默写背诵写作作业、整理错题、记待办——都放在同一个界面里。软件还内置了一个 AI 助手 TeachMate，考完试可以让它帮忙分析成绩、写报告、排复习计划。

几个主要特点：

- 数据都在本机。断网了除了 AI 对话，别的功能照常能用；
- 顶部可以一键切换"工作台"和"TeachMate"两种模式；
- 学校如果用 MONI 平台，配置一次之后学期、班级、学生、考试全部自动同步，基本不用手动录入；
- 数据按学期分开存，新学期不会动上学期的记录。

> 当前版本 0.9.0-beta.2，还是测试版。遇到问题先把数据备份好再反馈。

## 2. 安装与启动

macOS 双击 EnglishWorkBench.app。第一次打开如果提示"无法验证开发者"，去系统设置 → 隐私与安全性，点"仍要打开"。Windows 双击 EnglishWorkBench.exe 就行，不用安装；SmartScreen 弹提示的话，点"更多信息 → 仍要运行"。

启动后软件会自己检查并备份数据库，然后直接打开窗口，不用管。注意点窗口关闭按钮只是把界面藏起来，软件还在后台运行；要彻底退出，macOS 按 `Command + Q`，Windows 在托盘图标上右键"退出"。

数据都存在本机：macOS 在 `~/Library/Application Support/workbench/`，Windows 在 `%APPDATA%/workbench/`。把这个目录整个拷走，就等于把全部数据带走了，换电脑也是这么迁。

首次启动会先让你选一次任教学科（语文、数学、英语、物理、化学、生物、道德与法治、历史、地理、信息技术或其他）。学科决定界面用语与功能模块：默写、背诵、写作三个模块只对语文与英语开放，其它学科不会出现这三个入口，成绩列名也会跟着换成"语文总分""入学数学"这类说法。学科是数据目录级设置，换学期不用重选；空工作区可在"班级与设置 → 任教学科"中调整。录入考试、成绩、画像或其他教学记录后，本工作区会锁定学科，防止旧数据被当作另一学科使用；同时教多门学科时需要分别使用独立的数据目录。

主界面：顶栏有模式切换、学期和班级切换、导入、导出中心、备份/恢复；左侧是模块导航——仪表盘、学生管理、成绩管理、日常作业、原卷与错题、待办事项、班级与设置；语文和英语还会多出默写成绩、背诵成绩、写作成绩三个模块。

## 3. MONI 数据平台配置

> 完成一次 MONI 配置后，学期、班级、学生、考试（含成绩、分层线、逐题得分）会自动同步，日常使用零录入。

### 3.1 配置前需要准备什么

只需要学校（或平台）发的一个 MONI API Key，就是一串字符。接口地址、MCP 格式这些软件里已经内置好了，不用填。

### 3.2 配置步骤（约 2 分钟）

1. 打开软件，进「班级与设置」，找到「MONI 数据接口（MCP）」卡片；
2. 在「MONI API Key」输入框里粘贴 Key。Key 在哪里找：
   1. 打开 MONI agent 网页，点右上角自己的名字；
   2. 点「账号」；
   3. 往下拉，找到「API 密钥」，点复制就行；
   4. 如果页面上不能直接复制，只给了一段 MCP 格式的配置信息，把里面对应 API Key 的那串字符复制出来就行。
   - 输入框是密码框，输入时看不见内容；以前配过的话，留空就表示还用原来的 Key；
3. 点「保存接口配置」。保存成功后状态行会显示"API Key 已保存（••••••••××××）"，能看到 Key 的后 4 位，方便核对是不是贴对了；如果显示"API Key 尚未保存"，就是没存上，重新贴一遍；
4. 点「测试连接」。提示"MONI 连接测试成功"就说明配好了；提示"MONI 令牌未通过验证（HTTP 401）"的话，说明 Key 不对或者过期了，核对后重新输一遍；
5. 最后点「测试并同步学生数据」，做第一次同步，大概一两分钟。完成后状态行会显示结果，比如"同步完成 · 学生 45 人 · 班级 2 个 · 考试 3 场"，核对一下班级数、人数和实际是否一致。

到这里就配完了。以后每次打开软件，它都会在后台自动同步 MONI 当前学期的考试数据，打开就能直接看、直接分析，不用再管。

### 3.3 同步了哪些数据

- 学期、班级、学生名单，第一次同步时自动建好；
- 每场考试的名称、日期、满分，学生总分、班级排名；
- MONI 的英语分层（精英/重点/良好/常规）会自动换算成 A/B/C/D 层，分层线也填好，不用自己设；
- 逐题得分、题型和知识点标签，供 AI 分析用。
- 注意：年级排名暂时不能自动同步，需要的老师通过顶栏"导入数据"（Excel 里带"英语排名"列）或者手动录入补上。

## 4. AI 模型与 API Key 配置

> TeachMate 要配一个 AI 模型的 API Key 才能用。没配的时候其他功能都正常，只是发不了 AI 对话，发送按钮会提示"AI 分析尚未配置 API Key"。

API Key 要先去 AI 服务商官网申请。推荐下面二选一，从注册账号开始讲：

| | 方案一：DeepSeek | 方案二：智谱 GLM |
| --- | --- | --- |
| 申请官网 | platform.deepseek.com | bigmodel.cn（智谱开放平台） |
| 注册方式 | 手机号，也支持微信、邮箱 | 手机号 |
| 费用 | 按用量扣费，很便宜，要先充值 | 新用户一般有赠送额度，用完再充 |
| 软件里怎么配 | 点"添加模型"，接口地址都不用填 | 软件自带现成的智谱模型，填个 Key 就行 |

> 学校统一发了中转站 Key 的，找学校信息老师要配置说明，这里不讲这种情况。

### 4.1 配置入口在软件哪里

顶部切到 TeachMate，打开右上角的「设置」，进「模型」标签。列表里已经内置了"智谱 GLM"这些现成模型，内置的直接点旁边的「填写 API Key」就行；要用 DeepSeek 就点「添加模型」。

### 4.2 方案一：DeepSeek 从注册到配置

**第一步：注册账号**

1. 电脑浏览器打开 platform.deepseek.com；
2. 用手机号加验证码注册登录，也可以用微信或邮箱；
3. 页面如果提示实名认证，照着做一遍就行，只需要一次。

**第二步：充值**

DeepSeek 按用量扣钱，很便宜——做一次完整的考试分析一般就几分钱——但账户里得先有余额。登录后进「充值」页面，选个金额，微信或支付宝扫码付掉就行。

**第三步：创建 API Key**

1. 左侧菜单点「API keys」；
2. 点「创建 API key」，随便起个名字，比如"教学工作台"，确认创建；
3. 弹出来的 Key 马上复制保存。注意这个 Key 只显示这一次，关掉就再也看不到；真弄丢了就再建一个，把旧的删掉。

**第四步：回软件里填**

TeachMate 设置 → 模型 → 「添加模型」，照着填：

| 字段 | 怎么填 |
| --- | --- |
| 显示名称 | 自己好认就行，比如"DeepSeek" |
| 提供商 | 选 DeepSeek，接口地址会自动藏起来，不用管 |
| API Key | 粘贴刚才复制的 Key |
| 模型 | 下拉选 deepseek-chat 就好；想更快更省选 deepseek-v4-flash |
| 思考深度 / 能力 | 不用动，保持默认 |

然后点「测试连接」，看到"连接成功"再点「保存并应用」。

### 4.3 方案二：智谱 GLM 从注册到配置

**第一步：注册账号**

1. 浏览器打开 bigmodel.cn（智谱开放平台）；
2. 右上角「注册/登录」，用手机号注册；
3. 新用户一般有赠送额度（以官网活动页为准），可以先免费用一阵子，用完了再充。

**第二步：创建 API Key**

1. 登录后点右上角头像，进「API Keys」（有的版本在"个人中心"里）；
2. 点「新建 API Key」，起个名字，比如"教学工作台"；
3. Key 同样只在创建时显示一次，马上复制保存。

**第三步：回软件里填（这个最省事）**

软件里已经内置了配好的智谱模型，一般不用自己新建：

1. TeachMate 设置 → 模型，在列表里找到「智谱 GLM-4-Flash」；
2. 点旁边的「填写 API Key」，把 Key 粘进去；
3. 点「测试连接」，"连接成功"后点「保存并应用」。

想自己新建的话：点「添加模型」，提供商选智谱 GLM，接口地址会自动填好（一般不动它），模型 ID 填 `glm-5.3-flash`，然后粘贴 Key、测试连接、保存并应用。

> 小贴士：如果测试连接报"认证失败"，多半是 Key 和接口地址对不上。在智谱开放平台 bigmodel.cn 申请的 Key，把接口地址改成 `https://open.bigmodel.cn/api/paas/v4/chat/completions` 再试。

### 4.4 测试连接的几种结果

- 提示"连接成功"：点「保存并应用」，配完了，TeachMate 可以正常用；
- 提示"连接可达但余额不足（HTTP 402）"：Key 是好的，就是账户没钱了，去平台充值；
- 连接失败或认证错误：按顺序检查——Key 有没有复制完整（前后别多带空格）、接口地址对不对、电脑能不能上网。

模型可以同时存好几个配置，用每行的「使用」按钮切换，也可以随时「编辑」「删除」。Key 只存在自己电脑上，不会上传。

### 4.5 使用情况与计费

- 设置里的「使用情况」标签能看到用量统计，按今天 / 近 7 天 / 近 30 天 / 全部来筛，只统计用量，看不到对话内容；
- 默认就是按服务商 API 计费，用多少付多少；
- 还有个"预算控制"（花超了先弹窗问你再继续），默认是关的，一般不用管它。

## 5. 开始使用：建立学期与班级

配了 MONI（第 3 章）的老师这章可以跳过，学期、班级、学生都自动建好了。

没用 MONI 的，手动三步：

1. 建学期：顶栏学期切换器旁边点"＋"，输入名称，比如"2026-2027 学年第一学期"；
2. 建班级：进「班级与设置」添加班级；
3. 导学生：点顶栏「导入数据」选 Excel 文件，表格里至少要有"学号、姓名"两列，有"班级"列更好；一次选几个班的文件，会分别建成对应的班。人少也可以在「学生管理」里手动加。

学生档案有学号、姓名、班级、目标分、薄弱项、家长电话、座位这些字段，都跟着学期走。学生转学或退班用"归档"，别用删除——归档后历史成绩都还在，想恢复随时能恢复。

## 6. 日常工作台功能速览

### 成绩管理

配了 MONI 的，考试自动同步好（连分层线都有），不用导入。没配的，点顶栏「导入数据」导 Excel 或 CSV：表头在前 12 行以内，至少要有"学号、姓名、英语"三列；学号是匹配学生的依据，两边要一致。

新建或编辑考试时可以设满分、A/B/C 年级分层线、优秀线和及格线（按满分百分比填，优秀线要高于及格线）。排名、A 率、优秀率、及格率、分数段分布、ABCD 层级分布这些都是自动算的，同分并列同名次。

### 默写 / 背诵 / 写作 / 日常作业

四个模块长得差不多，分别记单词默写、课文背诵、作文得分和评语、作业完成情况。平时随手记一点，AI 分析学生的时候才有的看。

### 原卷与错题

考试原卷扫描件、错题照片都传到这里，软件里能预览能下载，文件就存在本机。

### 仪表盘

按当前学期和班级展示分层分析卡片、年级排名分布、ABCD 分布、历次趋势图、学生综合档案。班级切换器选"全部班级"就是年级视角。

### 待办事项

记点教学上的事，比如"找 3 个学生谈话"，做完勾掉。

### 导出中心

顶栏「导出中心」有四种导出：JSON 全量备份、学生名单 Excel、成绩分析 Excel、班级薄弱项 Word 报告。导出的文件在数据目录 `exports/` 里。

## 7. TeachMate AI 助手：三个教学工具怎么用

TeachMate 里最常用的是三个工具：分析考试成绩、学生诊断（也就是学生画像）、生成复习计划。它们都是直接读你数据库里的真实成绩来分析的。用之前先把第 4 章的 API Key 配好。

### 7.1 分析前先选好范围

切到 TeachMate，点"新建对话"进欢迎页，能看到三张工具卡片。输入框下方有两个选择器：

- 班级：选"全部班级"就是年级视角，也可以只看某个班；
- 考试：默认是"不选择考试 / 仅使用文字或文件"。想让 AI 拿到精确数据，就选一场考试——MONI 同步来的和自己导入的都在这个列表里。

使用“学生诊断”时，选好班级和考试即可生成全班执行方案。对话区会列出学生名单，输入区会要求你确认；确认前不会开始分析。如果只想看某一名学生，在问题中写明姓名或学号即可，不需要先去学生列表点选。

中途改了班级或考试再发送，会自动按新范围开一次新分析，之前的不受影响。

### 7.2 怎么问效果好

三个工具的卡片点开后，输入框里会自动填一句现成的问题，直接发送就能跑。但想让它说到点子上，最好在后面补几句自己的话。不用讲究什么格式，就像跟搭班老师交代事情一样，把三件事说清楚就行：

1. 看什么：整体情况，还是某段学生（尖子生、中等生、临界生），还是某个题型（完形、听力）；
2. 跟什么比：跟上一次考试比、跟入学时比、跟目标比；
3. 拿去干什么：自己心里有数、家长会上讲、教研发言、直接安排下周的课。

举个例子，同一个分析，两种问法差别很大：

- 笼统的问法："帮我分析一下这次月考。"——AI 也能出一份报告，但多半是常规套路；
- 具体的问法："这次月考跟入学考比，均分掉了将近 5 分。帮我看看主要丢在哪块，中等生是不是掉队了。周四教研要发言，结论帮我整理成三条。"——出来的发现和建议就有的放矢。

另外不用追求一次问全。报告出来后可以接着追问，比如"再把高分段里退步明显的学生列出来""第 2 条建议展开说说，具体到练什么题"。对话是有记忆的，它知道你在说哪份报告。

### 7.3 分析考试成绩

考完试想快速拿一份带数据、带教学建议的分析，就用这个。

1. 欢迎页点「分析考试成绩」卡片，预设的问题会自动填到输入框里，可以在后面补两句自己关心的；
2. 建议在"考试"选择器里选中本场考试，这样 AI 能拿到逐人成绩、分层分布、逐题得分这些精确数据，不是光凭你打的字来猜；
3. 有成绩单或试卷文件的话，也可以通过"工具"菜单传上去（文件在本地解析后会先给你核对），再点发送。

分析时界面上会显示进行到哪一步（正在读取数据、正在校验、正在生成回复），还有一条运行时间线，中途可以取消。

结果是一张「教学成果」报告卡：

- 结论摘要：一段话讲这场考试的整体情况；
- 主要发现：分数分布、试卷难度、薄弱知识点（得分率低于 60% 的）、典型错误类型（审题、词汇、语法之类），一条条编号列出来。每条后面有"来源"按钮，点开能看到数据出处和算法，方便核实；
- 行动建议：按优先级排好（P1 最急），每条都带理由；
- 卡片底部有数据质量说明，比如"统计基于 45 名有效成绩、2 名学生缺考"。

完整走一遍，假设要分析初三（1）班的第二次月考：

1. 班级选"初三（1）班"，考试选"第二次月考"；
2. 点「分析考试成绩」卡片，把输入框里的话改成："这次月考跟入学考比，均分和及格率变化怎么样？哪些知识点得分率最低？周四教研要发言，帮我把结论整理成三条。"
3. 点发送，等报告出来。先看"主要发现"里有没有跟你自己判断对不上的地方，点开"来源"核对一下数据；
4. 觉得哪里不够就追问，比如"再单独看看第 5 到 10 名的学生"；

### 7.4 学生诊断（学生画像）

想给全班建立学生画像，或者认真看某个学生为什么起伏并更新他的画像档案，用这个。

1. 切到 TeachMate 新建对话，选择班级和一场考试；
2. 欢迎页点「学生诊断」卡片，直接发送默认问法会先显示当前班级的执行方案和具体学生名单；
3. 在输入区点击“确认执行”后才会开始；也可以点“修改范围”，直接勾选或取消勾选要诊断的学生，再应用新的范围；
4. 只诊断某一名学生时，在问题里写姓名或学号；也可以写“80—90 分的学生”“A、B 层学生”缩小范围。

报告会讲这几块：

- 整体表现：总分、班级排名、跟班均的差距、在优秀/良好/合格/需提升哪一层；
- 优势在哪、薄弱在哪，薄弱的还会归一下原因（审题不清、词汇量不足这类）；
- 针对性建议：练什么、怎么调整学法、定什么阶段目标；
- 最后附一份学生画像的更新草稿：优势表现、重点薄弱项、学习习惯、阶段目标、跟进提醒这些。

画像怎么确认（这步重要）：

- AI 不会直接改学生档案，只交"草稿"，你点了确认才生效；
- 在报告卡上点「教师确认」，弹窗左边是 AI 原稿（不能改），右边是教师修改（可以自己动手改）；底部"学生个人画像待确认"区域一条条列着改动，点「确认写入画像」或者「拒绝」；
- 确认之后画像就更新了，会记下版本号和"最近确认"时间。以后也可以在工作台打开这个学生的详情，在"学生画像"卡片里看现在的画像、处理新的待确认变更；
- 弹窗里还能点"查看审计记录"，每次操作都有记录可查。

举个完整的例子。班里的小雨这次期中从班级第 8 掉到了第 19：

1. 成绩面板里点选小雨，回 TeachMate 新建对话，考试选"期中考试"；
2. 点「学生诊断」卡片，写明姓名并补充一句："小雨七年级一直在前十，这次掉得比较多。帮我看看主要丢在哪，是临场状态还是知识漏洞，给我两三条下周就能用的办法。"
3. 报告出来后，重点看"薄弱环节"和画像草稿——比如 AI 写了"阅读理解得分率明显下滑、听写错误集中在Unit 5之后的词"；
4. 点「教师确认」，先读左边的 AI 原稿，哪句跟你平时观察到的不符，就直接在右边改掉，再点「确认写入画像」；
5. 写入后，小雨的详情页"学生画像"卡片里就是这份新画像了，带着版本号和确认时间，组内其他老师打开也能看到。

觉得 AI 写得不贴切就点「拒绝」，画像保持原样，其他内容不受影响。

### 7.5 生成复习计划

考完试要把分析变成行动，用这个。它会排出未来两到四周的复习安排。

1. "考试"选择器里选好针对哪场考试（必须选，一般选最近一次）；
2. 欢迎页点「生成复习计划」卡片，有要求就补上，点发送。

计划长这样：

- 薄弱知识点排好了优先级：得分率低的排前面，也考虑了分值权重，每个点给了目标提升幅度；
- 分周安排：第一周练什么、第二周练什么，配基础/提高/挑战哪个难度的练习，什么时候安排阶段测评；
- 还会点出哪些学生需要专项辅导（报告里学生用编号表示，不直接写名字，你自己对照名单）。

还是接着上面那次期中考，假设距离期末还有三周、每周能排 4 课时：

1. 考试选"期中考试"；
2. 点「生成复习计划」卡片，补充："期末前还有三周，每周 4 课时。重点抓得分率最低的语法和完形，按周排，每周写清楚练什么、什么时候测。班里两头差距大，A 层和 C 层的任务分开列。"
3. 出来的计划按周组织：第一周攻得分率最低的点，配不同难度的练习，周中或周末安排阶段测评；
4. 对照自己的课表和进度，不合适就让 AI 改："第二周和运动会冲突，整体往后挪一周"；
5. 计划里的学生以编号表示，注意别把编号对应表随手外发。

### 7.6 几个通用操作

- 核对数据：发现卡下面有"来源"按钮，消息下面有"查看证据 (N)"，点开就是数据来源和计算公式；
- 深度思考：如果用的模型支持，回答里会有一个能折叠的"深度思考"面板，展开能看到推理过程；
- 遇到"任务已准备好"的确认卡：点"确认并继续"它才往下走，不想跑了就"取消任务"；
- 报告留在对话里，随时可以接着问，比如"再单独分析一下第 5 到 10 名的学生"。

### 7.7 其他（用不到可以不看）

- 欢迎页还有个"试卷录入"，能上传试卷自动提取题目结构；
- 输入框旁边的「工具」菜单可以导文件（PDF、Excel 等，本地解析后要你确认才进分析）、从资料库导入、调用插件；
- 设置 → 功能扩展里可以装本地插件包、开停 TeachMate 工具；
- WorkBuddy 是可选的：连上之后它能基于已完成的分析继续做 PDF、PPT，只读数据、默认不显示学生姓名，随时能断开。

## 8. 备份、恢复与数据安全

### 备份与恢复

- 软件升级前会自动备份数据库并做完整性检查，升级失败也不会动原来的数据；
- 平时想手动备份或恢复，点顶栏「备份/恢复」；
- 老版本导出的 JSON 备份，在「班级与设置 → 导入 JSON 备份」里恢复；
- 要跨电脑迁移、或者想定期做"数据库加附件"的完整备份，可以用附录里的命令行工具。日常教学用不上，可以不管。

### 数据安全

- 软件只在本机内部通信，不对网络开放，局域网里别的设备连不上；每次启动还会换一个新的访问令牌；
- 不依赖云服务，页面资源都在本地；家长电话这类敏感信息只存在自己电脑上；
- 学生、考试、学期默认先归档不真删，真要永久删除会先自动备份并记录影响范围；
- AI 那边：附件内容进分析前要你确认，画像修改要你确认，每条结论的数据来源都能查到。

## 9. 常见问题（FAQ）

**Q1：双击应用后没有反应？**
先确认应用已完全退出（macOS 用 `Command + Q`，Windows 在托盘右键退出），再重新双击；还是没反应就重启电脑试试，或者带上数据目录 `logs/` 里的日志来反馈。

**Q2：AI 提示"尚未配置 API Key"？**
按第 4 章，在 TeachMate 设置 → 模型里配好 Key，测试连接成功后点"保存并应用"。

**Q3：AI 回复报"余额不足"（HTTP 402）？**
Key 有效、网络也正常，就是服务商账户没钱了，去平台充值就好。

**Q4：MONI 测试连接报 401？**
Key 不对或者过期了，找学校/平台管理员核对后，在 MONI 配置卡片里重新输入并保存。

**Q5：配置了 MONI，但考试数据没有自动出现？**
先点"测试连接"确认 Key 有效，再点"测试并同步学生数据"手动触发一次。自动同步失败不影响软件启动，失败原因在数据目录 `logs/` 的日志里。

**Q6：导入成绩后有些学生没匹配上？**
检查成绩表里的学号和学生管理里的是否一致，学号是主要匹配依据；表头要在前 12 行以内，至少有"学号、姓名、英语"三列。

**Q7：断网了还能用吗？**
能。除了 AI 对话，其他功能全部离线可用。

**Q8：新学期旧数据会被覆盖吗？**
不会。所有数据按学期分开存，学生的目标分、薄弱项也跟着学期走。

**Q9：换电脑怎么迁移数据？**
方法一：旧电脑做完整备份，新电脑完全退出应用后按附录命令恢复。方法二：导出 JSON 全量备份，新电脑上"导入 JSON 备份"。

**Q10：不小心归档了学生/考试怎么办？**
到对应模块里点"恢复"就行，归档不删任何历史数据。

**Q11：AI 要写入学生画像，需要我确认吗？**
需要。AI 发起的画像修改都先以草稿形式提交，你确认后才生效，也可以驳回，全程有记录可查。
