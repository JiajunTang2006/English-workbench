# TeachMate 模拟课堂与真实模型测试 · 2026-09-30

测试当前 **1.0.0 源码**。按用户要求，同时调用软件中已经配置的 **智谱 glm-5.3-flash**；没有生成安装包、启动旧安装包或修改真实教学数据库。

## 测试方式

创建隔离的合成课堂：两个班、120 名学生、三次测验、逐题成绩、缺考与缺失小题记录，以及已确认试卷索引和阅读文本。两个班各有一个张晨，另有张晨曦，用来检验重名、相似姓名及连续换人。最终真实模型场景中，两位张晨的第 5 题分别为 **0.5/2.5** 和 **1.5/2.5**，避免相同成绩掩盖对象混淆。

只读取本机保存的模型配置与凭据，密钥仅在测试进程内使用；模型接收的是合成课堂数据。后端按正常应用生命周期启动，使用生产 Harness 路径及默认四个运行槽位。练习生成、反馈、复测和原文取舍走真实 Provider；不是录制响应或假模型。

这轮没有点击已安装应用、升级真实数据库或使用真实学生数据。浏览器回归访问临时测试服务。PDF 场景使用已解析文本和试卷索引，未做扫描件识别准确率或原生桌面 PDF 阅读器验收。

## 测试中修复的问题

1. **多槽位运行读不到选定考试。** 每个槽位保存范围文件的目录已独立，但工具进程的环境仍指向基础目录；真实模型因此回答“缺少范围”。两个启动路径现在均以槽位配置的目录为准。离线启动测试验证传入 SDK 的配置；真实模型验证查数成功。
2. **姓名与话题解析混淆。** 补充按出现位置匹配班级与姓名、较长姓名边界、陌生姓名追问和稳定引用边界。`student_100` 不再误匹配 `student_10`。明确指定两个比较对象时替换旧焦点；未知姓名清空对象，避免错误推题；普通教学话题不当作陌生学生。
3. **英语练习生成中文语篇。** 生成上下文现在明确携带学科，区分英语语篇/题干/选项和中文讲解。规范顶层 JSON 字段，阅读文本单独放入 `passage`。初轮新题复测未通过内容校验；规范输出契约后，两轮真实生成均通过。初轮未保存原始生成响应，不能断言其具体违规字段。
4. **真实聊天 Token 被记为 0。** 完整回合用量以 SDK 返回事件核对，替换未完成的异步投影，包含最后一次模型请求，并避免重复计数。报告修复回合额外用量一并计入；修复失败或未返回完整用量时标为未知。兼容两种用量事件名称。
5. **未知价格显示零费用。** 未登记价格时保留实际 Token，费用返回空值并在界面显示“未知”。用量表原有非空费用字段保留兼容占位；公开实际费用依据定价是否已知，不将占位解释为免费。
6. **复测越过教师指定的考查方式。** 中间轮出现需计算到达时间的阅读题；提示进一步要求原文直接定位时答案直接给出，复测不擅自改变已教方式。最终新题分别定位租船价格与俱乐部地点，答案可直接找到。
7. **后台刷新收起任务操作菜单。** 在同一任务与阶段保留打开状态；选择操作后正常收起。新增强制重绘断言。浏览器测试助手也修正首次学科弹窗异步出现及重复关闭导致的超时。

最终全量回归：后端 **1427 项通过、1 项默认跳过**（146.15 秒）；前端 **161 项通过**；全部页面 **51 项通过、1 项按原设计跳过**；JavaScript 语法、改动空白和敏感文件检查通过。后端最终一轮包含新增真实用量与报告修复回归，线上付费场景在普通测试中默认跳过，已在上面的专门真实模型验收中执行。页面跳过项是原设计仅在桌面执行一次的名单/成绩导入，桌面同用例通过。

记录：[前端](validation/teachmate-realistic-20260930/frontend.log)、[页面](validation/teachmate-realistic-20260930/e2e.log)、[后端](validation/teachmate-realistic-20260930/backend.log)。

这轮证明了配置模型下的关键流程和事实对象对应关系，没有证明长期课堂效果或所有第三方模型质量。内容走查仍看到：AI 有时附加未请求的板块得分；课堂建议会从低分进一步推测“定位不到句子”等原因，证据不足。原文租船题的正确答案可核对，但解析把一个干扰数字说成“文中其他数字”并不准确。此类内容仍须教师核对，后续质量评估应增加“事实/假设区分、仅回答所问、解析逐句证据”样本，不能把自动通过当作教育质量达标。

陌生姓名识别新增的是本地保守规则，尚不覆盖所有罕见姓氏、外文姓名及复杂称呼。真实课堂走查、跨模型对照、改造前后同条件 Token 对比和原生桌面 PDF 显示仍待验收。软件继续为 **1.0.0 源码，未制作新包**。
