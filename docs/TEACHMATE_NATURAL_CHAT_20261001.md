# TeachMate 自然聊天改造 — 2026-10-01

当前源码版本保持 **1.0.0**，按用户要求不制作新安装包。本记录替代前两轮的教学任务首页和任务式专项推题入口设计。

## 使用方式

恢复改造前的暖色聊天首页、欢迎图标、三个快捷入口、历史对话侧栏和底部输入框。撤下任务列表、任务表单、阶段、课时、任务画布等前端入口。历史任务、材料、练习及反馈的数据和兼容 API 保留，无破坏性迁移。

教师可直接输入“查看小明近期的薄弱知识点”。AI 可查最近考试的小分、真实失分题引用和教师已确认的画像；无需提前选择考试。只问薄弱点时回答证据，继续要求“找一道原错题”或“出三道专项练习”时再读题或设计练习。无需创建教学任务。

专项推题仍放在插件管理和输入框插件菜单中；“打开推题”选入聊天并保留输入草稿。消息携带可选插件标识，服务端检查启用状态并冻结本轮 skill；普通问答不加载整份 skill。两条模型运行路径共享该上下文。插件停用时拒绝所选插件请求，不留下孤立运行。

复习计划继续提供复习安排，练习与答案按教师需求提供。移除强制课堂讲评流程及四类教学包材料的要求，不自动生成教案。

## 证据、原题和模型兼容

- `get_student_learning_evidence` 默认查近三次实际参加的考试，最多六次；每次只返回题型小计、完整度和最多八道失分题引用，并附当前学期、本学科确认画像摘要。小分缺失保持缺失，画像标明历史判断，不能据此确定错因。
- `get_original_question` 只读取授权学生在当前学期、班级范围内的已确认试卷失分题；旧版试卷、无失分记录或跨范围引用被拒绝。返回题干、答案、考试、版本、题号及页码。
- 阅读只按索引读已有提取的附近来源页，不触发整卷 OCR；附近页不保证全文完整。超过正文预算时说明缺口，不能把缺页补成原文。skill 要求按学习目标判断全文、连续节选或无需原文，并区分原题巩固与新编练习。
- 名称解析沿用稳定学生引用，同名或近似候选需确认，学号和联系方式仍留在本地。新增读取绕过旧缓存，避免画像或原题修改后引用陈旧值。
- 无工具调用能力的第三方模型使用明确标注的本地学习证据预查，仍能自然回答；不能声称调用了未提供的原题工具。修复旧编排路径误用不存在的模型对象属性。
- 普通聊天循环最多四轮、一次一个查询。数据库汇总后再发送必要证据，避免整班画像、全部小分或整份 PDF 进入上下文。未对真实模型宣称 Token 节省比例。
