# TeachMate 首页调整与原生窗口验收

日期：2026-10-01。源码版本保持 1.0.0；未制作、安装或替换发行包。

## 首页调整

- 欢迎区改为小图标、简短标题和一句教学提示，去掉大型装饰图片与下划线。
- 左侧展示教学任务，右侧排列考试分析、学生诊断、复习教学包三个快捷入口。
- 新建任务放在任务区标题旁，归档入口移到区块底部。已有任务保留阶段、名称和教学目标。
- 输入框与内容区对齐，紧接主要入口。任务较多时在任务列表内滚动，避免整页被卡片撑长。
- 常用桌面尺寸保留双列，较窄页面改为单列；输入框保持可见，入口仍可滚动访问。

首页样式单独放在 `workbench-assets/teachmate-home.css`，作用域限制在欢迎页。现有聊天、任务编辑、插件和模型选择功能保持原有接线。

## 同时修复的交互问题

打开教学任务时，原先一个全局忙碌状态会阻止点击“任务内容”。聊天记录加载较慢时，用户看得到按钮却打不开内容。

现将内容展开、分类切换和返回内容等界面操作独立处理，不等待聊天读取；保存、修改等异步操作继续使用原有并发保护。页面回归用主动暂停聊天请求的方式检查：消息尚未返回时，可以打开已保存练习并切换到反馈。
