# 2026-09-02 学生诊断全班画像补丁记录

## 用户现象

- 插件仍显示为“学生个体诊断”；
- 发送学生画像请求时，界面要求补充某一名学生的姓名或学号；
- 无法直接对当前班级全体学生建立画像。

## 根因

全班任务组与并发学生诊断代码已经进入源码，但 `workbench.html` 仍引用旧版本号的
`teachmate-interactions.js`，浏览器或打包产物可能继续使用不支持全班路由的旧脚本。
此外，欢迎页的预设问法仍是“成绩波动较大的学生”，没有明确表达全班范围，容易让
教师和路由逻辑对范围产生不同理解。

## 修复

- 插件显示名统一由“学生个体诊断”改为“学生诊断”，内置插件版本提升为 `1.2.0`；
- 欢迎页默认问法改为“给当前班级所有学生做学生画像，并给出个性化提升建议”；
- 新建学生诊断未写姓名或学号时，默认创建当前班级的批量任务；
- 写明姓名或学号时继续走单人诊断；
- 支持“给当前班级做学生画像”等自然说法，即使没有先选择插件也能识别为全班任务；
- 保留按分数区间及 A/B/C/D 层筛选批量学生的能力；
- 提升 `teachmate-views.js`、`teachmate-tutorials.js` 和
  `teachmate-interactions.js` 的资源版本，强制补丁加载新脚本。
- Windows 构建原本已经包含 `plugins/`；补齐 macOS 构建与当前 PyInstaller
  规格中的内置插件目录，确保打包后仍显示新版插件名称和说明。
- 全班请求改为两阶段执行：第一次只创建 `waiting_confirmation` 方案，后端不调度；
- 修复“给当前班级所有学生做学生画像”被错误截取为单个学生姓名“做学生画像”的分流问题；明确的全班、全体、所有学生语义现在优先于单人姓名提取；
  对话区展示班级、考试、学生人数和具体名单，输入区显示“确认执行 / 修改范围 /
  取消”；只有教师点击“确认执行”后才进入队列。
- 确认方案不再向教师展示费用，改为展示预计 Token 用量；费用仍仅在后台作为确认门禁参数保留。
- 修复 TeachMate 侧栏功能/文件/历史分区在空间不足时互相挤压，固定前两段高度并仅让历史对话区域滚动。
- “修改范围”改为打开学生勾选器，默认勾选原方案名单；应用后重新生成待确认方案，不再直接把操作变成取消任务。
- 修复 TeachMate 滚动边界的“橡皮筋回弹”：消息区和侧栏改为禁止 overscroll 链式回弹，并关闭 Safari 惯性滚动层；同时将 TeachMate 弹层/方案卡的弹性缓动改为单调 `ease-out`，避免异步重绘时出现先超出再弹回。
- 资源缓存版本更新为 `202609022600`。
- 批量诊断完成后，子运行报告仍保留用于审计和写入学生画像，但不再回显到聊天区；聊天区仅保留任务组概览，并按“已完成 / 未完成 / 失败 / 已取消”统计。移除批量任务的“查看汇总”入口，避免再次展开逐人报告。
- 资源缓存版本更新为 `202609022700`。
- 针对并行任务偶发超时、限流或调度异常，批量子任务增加一次带短暂退避的自动重试；旧运行记录保留用于审计，重试仍失败的学生不会影响已完成画像。
- 批量任务结束后，任务卡新增“重新生成未完成学生”入口。教师可勾选失败/已停止学生再次生成，后端为选中学生创建新的运行记录并复用原任务位，已完成学生不会重复执行。
- 资源缓存版本更新为 `202609022800`。

## 2026-09-03 启动探测误报修复

- 截图中的 Uvicorn 已显示 `Application startup complete` 和 `127.0.0.1:8765` 监听，真正的问题是启动器健康探测的短暂失败；视觉模型未配置只影响图片/OCR能力，不阻塞文字与 MONI 功能。
- macOS 启动器改用直连 `127.0.0.1` 的本地 HTTP 探测，绕过系统代理；健康探测超时但当前子进程仍监听本地端口时增加安全兜底，并输出探测异常细节，避免把已启动服务误报为“数据服务启动失败”。
- 后续日志确认桌面会话 WebSocket 返回 403。根因是 `start_macos.command` 调用了没有安装 `pywebview` 的系统 Python，启动器退回带旧令牌的浏览器页；脚本现改为优先使用项目 `.venv/bin/python`，确保打开新的私有桌面窗口。
- 旧浏览器页若携带过期令牌，WebSocket 握手连续失败三次后停止无限重连并清理旧会话令牌，避免持续输出 403 干扰新实例。
- 实机反馈表明 macOS 内嵌 WebView 初始化缓慢且可能停留白屏；源码调试入口改为服务就绪后直接调用 Safari，正式打包 `.app` 的独立窗口行为不变。
