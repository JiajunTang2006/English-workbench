# TeachMate 数据生命周期

TeachMate 的数据分为三类，清理时不能混在一起处理。

## 1. 正式教学数据（不属于缓存）

- 学期、班级、学生、考试、成绩和题目结构；
- 正式原卷附件及已确认解析结果；
- 教师确认的学生画像、学生评价和其他人工修订。

这些数据只能通过各自的业务操作修改或删除，不受“清理 AI 缓存”影响。

## 2. AI 缓存（可以按学期清理）

- 试卷 AI 记忆（`exam_paper_memories`，包括草稿、已确认版本和旧版本）；
- TeachMate 对话、滚动摘要和消息附件关联；
- 分析运行记录、证据、运行事件和模型用量记录；
- 未确认的学生画像草稿、评价草稿和错因候选；
- 未晋升为正式资料的临时聊天文件。

这些内容用于让近期分析更连贯，但不是成绩事实。它们全部带有 `term_id` 或可通过
考试/会话追溯到学期，因此可以安全地按学期清理。

## 3. 系统知识库（不属于个人缓存）

项目内置的教学 Markdown 知识库及其编译索引是应用资源，不随学期清理。

## 清理规则

学期管理提供两个接口：

- `GET /api/v1/terms/{term_id}/cache`：只查看可清理数量；
- `POST /api/v1/terms/{term_id}/cache/clear`：教师明确确认后清理。

清理前会阻止仍有运行中分析的学期；正式附件、考试和成绩事实、教师确认的学生画像
与评价都会保留。当前不做自动删除，避免教师在未备份时误清理。

## 长期维护建议

1. 默认保留当前学期缓存，旧学期由教师手动清理。
2. 后续可增加“保留 30/90 天后提醒”，但自动删除应先生成缓存清单并要求确认。
3. 定期运行孤儿检查：清理没有会话、运行或数据库引用的临时文件。
4. 重要清理操作写入审计日志；在加入自动备份前，清理前应先完成一次工作台备份。缓存清理本身不提供对话恢复入口。
