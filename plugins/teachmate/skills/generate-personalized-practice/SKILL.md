# generate-personalized-practice

为明确的学生生成可直接使用的个性化练习。画像和逐题结果是约束条件，不能被模型臆测的信息替代。

## 工作流

1. **确定学生和范围**
   - 学生以姓名或学号出现时，先调用 `search_students`，限定 `term_id`，必要时限定 `class_id`。
   - 只有教师明确要求按姓名核对时才传 `identify=true`；后续输出仍优先使用 `student_anon_id`。
   - 如果用户已经提供稳定的 `student_id`，无需重复检索，但仍需确认当前学期归属。

2. **读取教学上下文**
   - 调用 `get_student_learning_profile` 获取当前学期已确认画像。
   - 调用 `get_student_practice_context` 获取薄弱知识点、错因分布和真实错题。
   - 需要限定最近一次考试时，向工具传入对应的 `exam_id`；不能猜测考试 ID。

3. **设计练习梯度**
   - 默认按“基础巩固 → 同类变式 → 迁移应用”组织题目。
   - 优先覆盖 `weak_knowledge_points` 和 `error_patterns` 中有证据支持的项目。
   - 原题只用于理解考点和错误模式，不直接复制题干、选项或答案。
   - 错因 `status=candidate` 或置信度较低时，只能作为训练假设，不能表述为确定诊断。

4. **输出练习**
   - 每道题给出题型、题干、选项（如适用）、答案、解析和训练目标。
   - 解析说明它针对的知识点/错误模式；不要暴露不必要的学生身份信息。
   - 题量、年级、难度、主题和题型以用户要求为准；未指定时生成 10 题，中等难度，分三档。
   - 明确标注哪些设计依据来自画像，哪些是模型为练习目的做的推断。

## 输出纪律

- 只读使用 TeachMate 数据；本 Skill 不创建、修改或确认画像，也不回写练习结果。
- 不把一次考试或单道题扩大为长期能力结论。
- 没有真实错题时，可以基于已确认薄弱点生成练习，但要明确说明缺少逐题证据。
- 如果工具返回空画像或数据不完整，先说明依据不足，再生成保守的基础练习。
