# 题型 → 能力 → 考点 → 错因 映射（考试分析主检索表）

来源：TeachMate 题型诊断映射（依据课标、2025 浙江中考公开评析和教学常理整理，
C 级；官方事实部分已在 exam-blueprint.md 单列）。用途：拿到试卷逐题数据后，
按题型定位优先检查的考点和错因；每个条目后半部分是该板块的训练方法。

## [QT-听力理解] 听力理解（含地区人机对话的理解性任务）
- 领域: 题型
- 级别: 三级
- 标签: 听力, 听力理解, 人机对话, 短对话, 长对话, 独白, 题型
- 可信度: C
- 来源: TeachMate 题型诊断映射（课标与浙江中考听力政策整理）
主要能力：理解主旨、获取关键信息、推断身份关系/意图态度，并利用语音线索理解
意义。优先考点：listening.gist、listening.detail、listening.inference；只有具体
听辨证据时才关联 listening.phonological_cues。
优先错因：词汇、定位、推断、审题。
诊断要点：先区分“没有听清/未识别语音形式”“听清词句但未整合信息”“信息已
获取但推断越界”。仅有总分或对错结果时不能认定为语音薄弱；应结合具体题目、
错误选项、复听表现或听辨记录。人机对话若包含口头输出任务，还应按当地评分维度
另行分析，不能直接套用本听力理解映射。
训练方法：听前预测场景和信息类型；首听抓主旨，复听记录人物、时间、地点、原因
和转折等关键词；答案必须回到录音证据；定期训练重音、意群、语调和常见连读，
但不把单次听错直接归因为发音问题。

## [QT-阅读理解] 阅读理解
- 领域: 题型
- 级别: 三级
- 标签: 阅读理解, 阅读, 题型
- 可信度: C
- 来源: TeachMate 题型诊断映射（课标与公开评析整理）
主要能力：获取、概括、推断、评价。优先考点：reading.detail、
reading.main_idea、reading.inference、reading.structure。
优先错因：定位、推断、审题、词汇。
诊断要点：先看错题集中在细节题还是推断题——细节题错多查定位习惯
（是否凭原词选答案、未核对同义改写），推断题错多查过度推断。
训练方法：先判断语篇主题、体裁和结构，再处理细节；重点训练推断、概括、
作者意图和段落作用；注意题干与原文的同义替换；不能只凭原词选择，
要核对逻辑和范围。

## [QT-完形填空] 完形填空
- 领域: 题型
- 级别: 三级
- 标签: 完形填空, 完形, 题型
- 可信度: C
- 来源: TeachMate 题型诊断映射（课标与公开评析整理）
主要能力：语篇逻辑、词汇搭配、情境推断。优先考点：vocab.collocation、
grammar.conjunction、reading.structure。
优先错因：词汇、推断、定位。
诊断要点：错题需区分句内搭配失分与上下文逻辑失分。错误选项只能作为候选
线索；除非解析明确说明干扰项设计，否则不能据此确定学生只凭单句语感作答。
训练方法：同时关注句内搭配、上下文逻辑和全文主题；代词、连词、动词和
形容词选项要结合语篇判断；对转折、因果、递进和时间顺序保持敏感；
做完通读全文检查情节和情感连贯。

## [QT-词汇运用] 词汇运用
- 领域: 题型
- 级别: 三级
- 标签: 词汇运用, 词汇题, 词形变化, 题型
- 可信度: C
- 来源: TeachMate 题型诊断映射（课标与公开评析整理）
主要能力：词义、词性、词形和拼写。优先考点：vocab.meaning_context、
vocab.part_of_speech、vocab.word_formation、vocab.spelling。
优先错因：词汇、语法、审题。
诊断要点：区分词义不识、词性判断错、词形变化错、拼写错四类，干预不同。
训练方法：词汇题区分词义、词性、固定搭配和语境；做题后检查答案是否符合
上下文意义。

## [QT-语法填空] 语法填空
- 领域: 题型
- 级别: 三级
- 标签: 语法填空, 语法题, 题型
- 可信度: C
- 来源: TeachMate 题型诊断映射（课标与公开评析整理）
主要能力：句法分析和形式选择。优先考点：grammar.tense、grammar.voice、
grammar.nonfinite、grammar.number。
优先错因：语法、审题、词汇。
诊断要点：错误集中在个别语法点（如时态）还是随机分布——前者按知识点专项补，
后者说明句法分析流程缺失。
训练方法：不能只看空格所在句，要分析整个句子结构；重点复习时态、语态、
非谓语动词、名词单复数、代词、比较级和词性转换。

## [QT-任务型阅读] 任务型阅读
- 领域: 题型
- 级别: 三级
- 标签: 任务型阅读, 信息整合, 开放任务, 题型
- 可信度: C
- 来源: TeachMate 题型诊断映射（课标与公开评析整理）
主要能力：信息整合和真实任务回应。通用优先考点：reading.detail、
writing.task_completion；材料同时包含图片、表格、符号或其他非文字资源时再关联
reading.multimodal；仅当题目内容明确要求描述、调整或评价学习方法时，才关联
learning_strategy。
优先错因：定位、推断、表达、审题。
诊断要点：既有信息理解失分，也有任务回应失分（答非所问、只写关键词），
两类要分开归因。2025 年第 35 题"How do you learn English?"属迁移创新层，
并可关联 learning_strategy；该关联不能泛化到其他年份的全部任务型阅读。
训练方法：先明确任务对象、答题格式和信息来源；既要理解原文也要联系自己
的经历；回答简洁完整，注意人称、时态和句式一致。

## [QT-书面表达] 书面表达
- 领域: 题型
- 级别: 三级
- 标签: 书面表达, 作文, 写作, 题型
- 可信度: C
- 来源: TeachMate 题型诊断映射（课标与公开评析整理）
主要能力：内容、组织、连贯、准确和得体。优先考点：writing.task_completion、
writing.organization、writing.coherence、writing.language_accuracy。
优先错因：审题、语法、表达、词汇。
诊断要点：写作失分要区分"任务未完成"（漏信息点）与"语言不准确"
（时态/主谓一致/拼写），前者改审题习惯，后者做语言专项。
训练方法：先列出题目要求的全部信息点；开头点题、主体展开、结尾收束；
优先使用熟悉且准确的句型；适当加入原因、例子、转折或结果；
完成后检查时态、主谓一致、名词单复数、拼写和标点。
