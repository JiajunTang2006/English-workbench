# 复习任务与计划素材

来源：TeachMate 复习任务与掌握度框架（依据课标、2025 浙江中考公开评析和
教学常理整理，C 级）。用途：生成复习计划（review_plan）时的活动素材库——计划的
"行动建议"应尽量落到这些可执行任务，而不是泛泛的"加强练习"。

## [RV-路径-总纲] 六步复习路径
- 领域: 备考
- 级别: 三级
- 标签: 复习路径, 备考路径, 总纲
- 可信度: C
- 来源: TeachMate 复习任务框架（课标与公开评析整理）
1. 夯实基础：整理高频词汇、常见音形对应、基本句型和核心语法；
2. 按语篇训练：在听力和阅读材料中练习信息获取、概括、推断和逻辑判断；
3. 按能力分层：把错题标记为理解、应用或迁移问题；
4. 限时整卷训练：按当地考试组成训练听力/人机对话与笔试的节奏、取舍和整体规划；
5. 针对性复盘：记录错误原因，而不只是抄写正确答案；
6. 强化输出：定期完成阅读理解中的任务题和书面表达，形成自己的表达素材库。

## [RV-任务A] 阅读证据链训练
- 领域: 备考
- 级别: 三级
- 标签: 阅读训练, 证据链, 定位训练, 推断训练
- 可信度: C
- 来源: TeachMate 复习任务框架·任务A
目标：提升细节定位、同义改写和推断能力。
步骤：写出题目要求的对象和范围 → 圈出题干中的人名、时间、地点、动作和
逻辑词 → 在原文定位证据句 → 将原文证据改写成自己的答案 → 标注答案属于
"直接信息"还是"推断信息" → 若选错，记录是定位错误还是推断越界。
默认观察门槛（教师可调整）：连续完成 3 篇不同体裁语篇，每篇主旨、细节和推断题都能说明证据
位置与理由。适用考点：reading.detail、reading.paraphrase、reading.inference。

## [RV-任务B] 完形逻辑复盘
- 领域: 备考
- 级别: 三级
- 标签: 完形训练, 复盘表, 上下文逻辑
- 可信度: C
- 来源: TeachMate 复习任务框架·任务B
目标：避免只凭单句语感做题。
方法：用复盘表逐空记录——句内线索 / 段落线索 / 全文主题 / 正确选项理由 / 错因。
默认观察门槛（教师可调整）：能为至少 80% 的空格写出"为什么这个选项比其他选项更合适"，
而不是只写词义。适用考点：vocab.collocation、grammar.conjunction。

## [RV-任务C] 语法填空句法还原
- 领域: 备考
- 级别: 三级
- 标签: 语法训练, 句法还原, 填空流程
- 可信度: C
- 来源: TeachMate 复习任务框架·任务C
目标：将"凭感觉填空"变成可解释的句法流程。
固定流程：找主句主语和谓语 → 判断空格所在成分 → 判断时间、语态和逻辑关系
→ 决定词性或动词形式 → 放回原句朗读检查语义 → 通读语篇检查时态和指代一致。
默认观察门槛（教师可调整）：连续两组练习中，能对错题明确指出是结构判断错误还是形式变化错误。
适用考点：grammar.tense、grammar.voice、grammar.nonfinite。
与课标"形式—意义—使用"语法观一致（LK-语法-三级）。

## [RV-任务D] 书面表达信息覆盖
- 领域: 备考
- 级别: 三级
- 标签: 写作训练, 信息覆盖, 自检清单
- 可信度: C
- 来源: TeachMate 复习任务框架·任务D
目标：降低"语言不错但任务没完成"的失分。
提交前清单：是否回应题目中的每一个问题；是否明确对象、时态和人称；
是否有至少一个具体例子或细节；段落顺序是否清楚；是否使用合适的连接词；
是否检查拼写、主谓一致、名词单复数和标点；是否出现与题目无关的套话。
默认观察门槛（教师可调整）：连续 3 次作文都能在草稿中先列信息点再结构化表达。
适用考点：writing.task_completion、writing.organization。

## [RV-任务E] 听力证据链训练
- 领域: 备考
- 级别: 三级
- 标签: 听力训练, 听辨, 关键信息, 复听, 人机对话
- 可信度: C
- 来源: TeachMate 复习任务框架·任务E（依据课标与浙江中考听力政策整理）
目标：区分听辨、信息整合和推断问题，避免只反复播放而不记录证据。
步骤：听前根据题干预测场景与信息类型 → 首听记录主旨和人物关系 → 复听记录时间、
地点、原因、转折等关键信息 → 写出答案对应的录音证据 → 对照文本或教师解析，判断
失分属于未听清、词义不识、信息定位还是推断越界 → 对未听清片段做跟读和再次听辨。
默认观察门槛（教师可调整）：连续 3 组不同场景材料中，能为主要错题指出录音证据
并区分听辨、定位和推断问题。适用考点：listening.gist、listening.detail、
listening.inference；有复听证据时再标 listening.phonological_cues。
地区采用人机对话考试时，口头输出部分须另按当地任务和评分标准训练。

## [RV-模板-七天] 七天复习计划模板
- 领域: 备考
- 级别: 三级
- 标签: 七天计划, 计划模板, 周计划
- 可信度: C
- 来源: TeachMate 七天复习计划模板
第1天 命题方向：读语篇标注主题和体裁（reading.topic）；只有任务明确要求文化
信息获取、比较或价值判断时才标 cultural_awareness；
第2天 细节定位：细节题和同义改写题，记录证据句（reading.detail、reading.paraphrase）；
第3天 推断与结构：推断题、主旨题、段落结构题（reading.inference、reading.structure）；
第4天 词汇与完形：搭配、词性和上下文逻辑复盘（vocab.collocation、vocab.part_of_speech）；
第5天 语法：语法填空逐空写句法依据（grammar.tense、grammar.voice、grammar.nonfinite）；
第6天 输出：一篇阅读理解中的任务题和一篇书面表达（writing.task_completion、writing.organization）；
第7天 整卷与复盘：限时训练，按六类错因归档（审题/词汇/语法/定位/推断/表达）。
听力安排：根据当地考试形式，将任务E作为每日 10~15 分钟微任务，或替换一天的
书面专项；不得用省级笔试结构推定当地听力/人机对话题型。
用途：review_plan 生成周安排时的候选骨架。只安排有考试或学习证据支持的薄弱点，
并按班级/学生实际情况替换、增删或调整每天焦点，不要求机械执行七天顺序。

## [RV-规则-掌握度] 掌握度判定与练习生成约束
- 领域: 备考
- 级别: 通用
- 标签: 掌握度, 练习生成, 约束
- 可信度: C
- 来源: TeachMate 掌握度与练习生成默认规则
以下门槛是 TeachMate 默认观察规则，可由教师调整，不是课标规定，也不能据此
证明长期掌握。掌握度门槛：未验证（只看过讲解）/ 初步掌握（提示下完成 1 次）/ 可独立应用
（独立完成 2 次不同语境任务）/ 稳定掌握（3 次以上不同题型且能解释理由）/
待迁移（新情境未验证）。画像和计划中的"目标达成"表述应使用该口径。
练习生成约束：正式诊断和综合训练优先使用完整语境；针对单一形式错误时可少量
使用单句练习，但随后应安排语篇或真实任务中的迁移。阅读题必须能指出原文证据范围；推断题
必须有足够文本证据；词汇题至少考词义/词性/搭配/词形之一；语法题提供完整
语境；开放题明确任务对象、内容要求和输出形式；解析区分"证据、规则、结论"；
不声称预测真实中考。
