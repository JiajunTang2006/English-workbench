# 六类错因：定义、表现、干预与置信度规则

来源：TeachMate 错因诊断框架（依据课标、2025 浙江中考公开评析和教学诊断常理
整理，C 级）。错因一级分类与 TeachMate 数据模型 `ErrorCauseAssessment.cause`
的六类一致：
审题 / 词汇 / 语法 / 定位 / 推断 / 表达。单题可有多个候选错因。

## [EC-错因-审题] 错因：审题
- 领域: 错因
- 级别: 三级
- 标签: 审题, 审题不清, 没看清题目
- 可信度: C
- 来源: TeachMate 错因诊断框架（公开评析与教学常理整理）
定义：没有正确理解题目任务、限制或答题对象。
典型表现：问原因却答结果；忽略 not/except；漏看字数或格式要求。
首选干预：圈出任务词、对象、范围和限制。
数据线索：答案方向与题干要求明显错位、阅读理解中的任务题答非所问。

## [EC-错因-词汇] 错因：词汇
- 领域: 错因
- 级别: 三级
- 标签: 词汇, 单词不认识, 搭配不当
- 可信度: C
- 来源: TeachMate 错因诊断框架（公开评析与教学常理整理）
定义：单词、短语、词形、搭配或音形义对应知识不足。
典型表现：不认识关键词；词性转换错误；搭配不当；听力中无法把熟悉词义与实际
语音形式对应。若涉及重音、意群、语调或连读等纯听辨问题，应在详情中注明
“听辨/语音线索”子标签，不能仅凭听力得分笼统归为词汇。
首选干预：词义—词性—搭配—语境四步复习。
数据线索：词汇运用/完形错题、所选选项词义偏离、拼写错误。

## [EC-错因-语法] 错因：语法
- 领域: 错因
- 级别: 三级
- 标签: 语法, 时态错误, 句法
- 可信度: C
- 来源: TeachMate 错因诊断框架（公开评析与教学常理整理）
定义：句法结构或形式规则判断错误。
典型表现：时态、语态、主谓一致、非谓语错误。
首选干预：先还原句子骨架，再确定形式。
数据线索：语法填空错误、写作中时态/一致类划扣。

## [EC-错因-定位] 错因：定位
- 领域: 错因
- 级别: 三级
- 标签: 定位, 没找到证据, 张冠李戴
- 可信度: C
- 来源: TeachMate 错因诊断框架（公开评析与教学常理整理）
定义：没有找到或筛选正确的口头/书面语篇证据。
典型表现：把相邻信息当答案；漏掉同义改写；听到相关词但未锁定正确人物、时间
或事件。
首选干预：标出题干关键词，并定位录音片段或原文证据句。
数据线索：细节题选了"原文出现过原词"的干扰项。

## [EC-错因-推断] 错因：推断
- 领域: 错因
- 级别: 三级
- 标签: 推断, 过度推断, 逻辑跳步
- 可信度: C
- 来源: TeachMate 错因诊断框架（公开评析与教学常理整理）
定义：证据不足、逻辑跳步或过度推断。
典型表现：原文没有支持却选择"看起来合理"的选项。
首选干预：采用"证据—结论—范围"检查。
数据线索：推断题失分但细节题正确。

## [EC-错因-表达] 错因：表达
- 领域: 错因
- 级别: 三级
- 标签: 表达, 输出不完整, 格式
- 可信度: C
- 来源: TeachMate 错因诊断框架（公开评析与教学常理整理）
定义：理解正确但输出不完整、不准确或不合格式。
典型表现：漏信息点、句子残缺、组织混乱、表意不清或格式不符。时态、句法、
词形和拼写错误分别优先归入语法或词汇；只有同时造成信息表达不完整时才兼列表达。
首选干预：使用输出清单和提交前自检表。
数据线索：阅读理解中的任务题/书面表达中理解基本正确但答不完整、组织不清或格式不规范。

## [EC-规则-置信度] 错因置信度判定规则（重要）
- 领域: 错因
- 级别: 通用
- 标签: 置信度, 判定规则, candidate, 教师确认
- 可信度: C
- 来源: TeachMate 错因置信度规则（对齐项目数据字段）
- 只有分数或对错结果（仅有 score/correct）：最多标记为**低置信度候选**；
- 只有 selected_option：通常仍为低置信度候选；仅当题目解析明确说明干扰项设计
  且错误选项与某类错误表现一一对应时，才可升为中等置信度；
- 有 student_answer_text：可依据答案表现缩小审题、词汇、语法、定位和表达的
  候选范围，但不能仅凭答案反推完整思维过程（推断尤其需要更多证据）；
- 有清晰作答过程或批注：才适合提高错因置信度；
- 教师确认结果优先于 AI 判断（对应数据模型 status: candidate → confirmed）；
- **不把"阅读理解""完形填空"直接当作错因，它们是题型，不是根因**。
实现提示：AI 生成错因候选时必须按本规则选 confidence 档位并写明依据；
缺作答痕迹时不得输出高置信度错因结论。
