# TeachMate 教学知识库

本目录存放内置教学知识库**源条目**，供三个教学插件（考试分析 / 学生诊断 /
生成复习计划）引用"教学依据"。

运行时知识注入采用 v2 省 Token 架构（见 `docs/KNOWLEDGE_BASE_RAG.md`）：
模型默认读不到条目全文——服务端从条目**预编译**出诊断卡/精华表/路由表后
按作用域组装简报注入；条目全文只通过深查工具 `get_teaching_guidance`
按需返回。因此**条目是唯一事实源**：改动条目后必须同步更新派生产物
（`compiled/`，构建期有过期校验）。检索结果一律登记为 evidence
（`teaching_reference`），与成绩类证据一样可追溯。

## 两套分类体系的关系

知识库使用两层词汇，条目互相引用，不许混用：

1. **考点 ID（能力诊断层）**：`capability-points.md` 定义的 `listening.detail`、
   `reading.detail`、`vocab.collocation`、`grammar.tense` 等 38 个考点。粒度对应"考试怎么考"，
   用于试卷题目标注、逐题/知识点聚合、薄弱点排序和错因归因。
   **试卷 `knowledge_nodes_json` 标注优先使用考点 ID。**
2. **知识内容层**：课标语法项目（一般过去时、宾语从句……）等内容单元。
   考点是"考查动作"，课标项目是"语言内容"，一个考点通常关联若干课标项目
   （如 `grammar.tense` ↔ 一般现在时/一般过去时/现在完成时…），
   关联关系写在语法条目的"关联考点"字段。

## 条目格式（重要：检索按此解析，格式不能随意变）

一个文件包含若干条目，条目是**最小检索单元**。条目格式：

```markdown
## [条目ID] 条目标题
- 领域: 语法            ← 必填，取值见下
- 级别: 三级            ← 可选，一级/二级/三级/三级+/通用
- 标签: 宾语从句, 从句, 主从复合句   ← 必填，逗号分隔的检索标签
- 可信度: A             ← 可选，A=官方明确 / B=出版信息 / C=TeachMate整理或建议 / D=待确认；缺省 C
- 来源: 课标2022 附录4   ← 必填，便于追溯
条目正文（紧凑的干货，供注入 AI 分析上下文）。
```

规则：

1. **条目 ID** 全库唯一，格式 `[类型缩写-领域-名称]`，如 `[KG-语法-宾语从句]`、`[AQ-听-3-1]`、`[EC-错因-审题]`。
2. **领域** 固定取值：`考点 / 语法 / 词汇 / 语音 / 语篇 / 语用 / 技能 / 策略 / 素养 / 主题 / 文化 / 错因 / 题型 / 备考 / 案例`。
3. **标签** 是一检索引的匹配键：写教师和 AI 会实际使用的称呼（标准名 + 常见俗名），如
   "宾语从句"条目应带 `从句, 宾语从句, object clause`。语法类标签必须与
   `curriculum-2022/grammar-taxonomy.md` 的类目名一致；试卷逐题标注优先使用
   `capability-points.md` 的考点 ID。
4. 条目正文以语义完整和低 Token 为原则：事实/分类条目通常 30~300 字，诊断/
   干预条目通常 80~500 字，不为满足最低字数扩写。只写"AI 分析时要用的判断依据
   和建议素材"，不写通识介绍。经验类条目按"常见错误表现 / 归因 / 干预方法 /
   练习建议"组织。
5. OCR 来的材料必须重写为干净文本，不搬运表格破碎的原文；来源字段保留原页码/表号。
6. 引用观点性内容（非官方原文）须保留"建议/推断"措辞，可信度标 C，
   不得写成确定性事实——与 `exam-zhejiang-2025/exam-blueprint.md` 的证据等级规则一致。
7. TeachMate 自建的考点、错因、题型映射、干预任务和掌握度门槛一律标 C；即使
   依据官方材料整理，也不得把项目分类写成课标或出版物原有分类。A 级条目中
   不混入诊断建议；官方事实与 TeachMate 映射应拆成不同条目。
8. 仅依据公开评析或书目信息、未核对原书全文时，文件导言和来源字段必须明确
   说明，不能使用"原书明确指出"等表述。
9. 浙江中考英语笔试由省级统一命题，听力或替代的人机对话任务由设区市自主选择
   并命题。听力知识只能提供跨地区通用能力和诊断边界；具体题型、题号、分值细则
   与评分维度必须按地区和考试年份记录，不能泛化为全省统一事实。

## 与知识点分类表的关系

`curriculum-2022/grammar-taxonomy.md` 承担双重角色：

1. 课标语法知识的条目化（本知识库一部分）；
2. 试卷录入（exam_ingestion）AI 标注知识点时允许挂载的**类目白名单**——
   AI 提出分类表之外的类目时，应作为"草拟新类目"提交教师确认，确认后先补
   分类表再补条目。
