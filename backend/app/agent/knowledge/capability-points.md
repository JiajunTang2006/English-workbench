# 考点词表（能力诊断层）

考点是 TeachMate 为考试分析建立的"考试怎么考"诊断单元，依据《义务教育英语
课程标准（2022 年版）》、浙江中考考试政策和 2025 年浙江中考公开试题评析整理，
不是课标或《2025 年浙江省中考命题解析·英语》原有的官方分类。用途：

1. 试卷录入（exam_ingestion）的逐题知识点标注，**优先使用考点 ID 作为标签**；
2. 逐题/知识点聚合（get_question_difficulty / get_knowledge_coverage）的归组口径；
3. 学生诊断的薄弱点表述和复习计划的任务锚点。

粒度原则：考点是稳定、可归并的"考查动作"；同义名称必须归并到已有 ID，
不得为同一考点重复建点。与课标知识内容层的对应关系写在各条目"课标关联"。

听力说明：浙江中考英语听力由设区市自主命题，部分地区可采用人机对话考试替代，
具体任务形态可能不同。以下听力考点只提供跨地区通用能力标签，实际标注须以当地
当年考试方案和题目为准。

## [CP-听力-主旨大意] 听力主旨与场景
- 领域: 考点
- 标签: listening.gist, 听力主旨, 场景判断, 主题大意
- 可信度: C
- 来源: TeachMate 考点分类体系（依据课标2022及浙江中考听力政策整理）
识别对话或独白的主题、场景和主要内容。常见证据：主旨题、场景题。
课标关联：七至九年级理解性技能中的口语语篇主题、大意、主旨要义理解。

## [CP-听力-关键信息] 听力关键信息获取
- 领域: 考点
- 标签: listening.detail, 听力细节, 关键信息, 时间地点人物
- 可信度: C
- 来源: TeachMate 考点分类体系（依据课标2022及浙江中考听力政策整理）
获取并梳理人物、时间、地点、事件、原因和结果等关键信息。常见证据：短对话、
长对话或独白中的事实细节题。
课标关联：学业质量 3-1、3-3；三级理解性技能中的关键信息获取与梳理。

## [CP-听力-推断判断] 听力推断判断
- 领域: 考点
- 标签: listening.inference, 听力推断, 身份关系, 意图态度, 情节预测
- 可信度: C
- 来源: TeachMate 考点分类体系（依据课标2022及浙江中考听力政策整理）

常见证据：身份关系题、意图态度题、情节预测题。
课标关联：学业质量 3-2；八、九年级理解性技能中的关系、态度和意图推断。
